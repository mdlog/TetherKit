Record at 1080p60, with a picture-in-picture of a hand holding a real phone. Use no copyrighted music. All in-app sounds are procedural and safe to keep.

Tips:
- Close the pairing card's "Show QR" before the 3D shot so the model is centered.
- Before the phantom-beam segment, click the desktop page once so its audio is unlocked.
- On iPhone, the ringer switch can mute Web Audio in older iOS versions. Recent Safari is put in "playback" mode automatically.
