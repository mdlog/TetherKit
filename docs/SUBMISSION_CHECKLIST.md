# Kiroween 2026 submission checklist

Deadline: **Friday, Dec 4, 2026, 2:00 PM PT** (Saturday, Dec 5, 05:00 WIB). Submission period: Oct 30 – Dec 4, 2026. The project must be new and built in that window.

## Repository (Skeleton Crew)
- [x] `LICENSE` (MIT) at the root, so GitHub shows it in **About** — *update the copyright holder name if you like*
- [x] `/.kiro` at the root with specs, steering and hooks, **not** in `.gitignore` (the `guard-kiro-not-ignored` hook watches this)
- [x] Two separate app folders: `tether-deck/` and `phantom-beam/`, plus the skeleton in `tetherkit-core/`
- [x] All source, assets and instructions needed to run (`README.md`, `docs/`)
- [x] `THIRD_PARTY_NOTICES.md`
- [x] Create a **public GitHub** repo (not GitLab or Bitbucket), push, and confirm the license badge and `.kiro/` are visible on github.com: https://github.com/mdlog/TetherKit

## Working app
- [ ] Deploy the relay plus both apps over HTTPS ([DEPLOYMENT.md](DEPLOYMENT.md))
- [ ] Incognito smoke test, including the Virtual Phone path
- [ ] No login needed, so no credentials for judges
